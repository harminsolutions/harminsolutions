# Harmin Solutions — Signature Edition 2026

This is a complete, standalone static website. Extract the ZIP **before** opening `index.html` in your browser. Do not remove the `assets` directory or the CSS/JS files.

## Contents
- `index.html` — complete website
- `styles.css` — responsive styles and animations
- `script.js` — welcome introduction, mobile navigation, progress bar, scroll reveals and expandable services
- `favicon.png` — Harmin symbol for the browser tab
- `assets/` — user-supplied founder photograph, project/client/partner logos, original manufacturer logos and product images

## Notes
- The founder photograph is the original transparent image supplied by the user, displayed with `object-fit: contain`, without altering facial details.
- Manufacturer logos represent brands of computer products supplied; their appearance does not imply direct manufacturer authorization.
- EduIntel is labelled **Under Development**.
- Service descriptions are plain English and expandable. Only one service is expanded at a time.
- Contact actions use WhatsApp, email, Facebook and Instagram links; no form backend is required.
- Google Fonts are optional; built-in system-font fallbacks keep the website usable without Internet.

For deployment, upload all files with the same directory structure to your static hosting service.
